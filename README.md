Train forcus
=================
Train focus is a website to help you focus. The theme of the website is Japanese train. You will like have a train journey when you focus.
## Feature
1. BGM
   In the focus journey, you will be hear the sound of the train
2. Scoreboard
   There is a scoreboard competewith other user
3. Real-like Time
   The time of the focusing is similar to the reality train travel times
https://trainfocus.free.nf/index.php
